# V1.1（1.1.0）

详情取得影视名称后自动预搜索；电影、电视剧全集及各季按类型、TMDB ID 和搜索词分别缓存。下载窗口立即打开，正在进行的预搜索直接复用，后台每秒更新一次结果。已完成的搜索（包括空结果）在服务端内存缓存 30 分钟，重启应用后重新搜索；当前页面再次打开下载窗口直接显示缓存。

链接以每批 40 条、每个搜索最多 4 批并行验证。每批完成后逐步显示 `state=ok` 的链接；其余状态不会当作有效链接。验证接口不可用时显示失败提示，5 秒后允许重新发起搜索。已验证的部分结果仍可使用。缓存表示验证时的快照，不能保证链接在之后始终有效。

搜索缓存最多保留 100 项，满时返回繁忙提示，过期项自动清理。缓存不写入用户数据库。季数切换及页面退出后忽略旧请求，避免结果串用及持续轮询。

## 升级

FPK 版本为 `1.1.0`，保留原包 `appname=movicloud-pansou`、端口 `15079`、`MOV_DATA_DIR=${TRIM_PKGVAR}/data` 和生命周期脚本。适用于相同应用标识且已安装版本低于 1.1.0 的 x86_64 fnOS。先备份应用数据和旧包，然后在应用中心手动安装新包并确认显示升级；不要卸载旧版。PanSou 仍使用 `http://127.0.0.1:8088`，须支持 `/api/check/links`。

## 验证范围

自动化行为测试覆盖立即返回、并发请求复用、30 分钟失效、空结果缓存、影视及季数隔离、验证失败重试、分批并发及逐步发布、窗口立即打开、前端缓存、旧请求隔离及页面退出。完整 Nuxt fnOS 构建用于验证所有现有页面、接口和组件能编译。原个人网盘与转存实现保留。

已连接 fnOS，在独立 Docker 容器 node:22-bookworm 中完成 Linux x86_64 原生编译、5 组行为测试，以及编译后应用启动、初始化、登录/bcrypt、认证搜索、后台验证、缓存、主页及认证拒绝测试。现有 PanSou /api/check/links 实测返回 HTTP 200，并正确识别明确无效的示例链接。

NAS 当前应用为 1.0.8，生成 1.1.0 升级包，保留原应用标识、端口、数据目录和升级脚本。尚未执行已安装应用升级，也未操作真实账户验证夸克/UC 转存；Docker 中使用独立测试数据与模拟搜索服务。
